# Learn Notion with Phoebe

Six 45-minute sessions on building one Notion workspace that stays true: pages against databases,
properties chosen by the question they answer, relations and rollups so one fact lives in one
place, a drift bench, Formulas 2.0, templates and buttons, and a Monday dashboard.

The running case, Ines, a freelance user-research consultant, is constructed for teaching.

- `index.html` - landing page and knowledge map
- `courses/01` to `06` - the sessions; session 4 is the drift bench
- `assets/nt-live.js` + `assets/nt-sample.js` - the bench engine and its constructed, seeded rows
- `materials/nt_reference.py` - independent Python reference; `node materials/nt-node.js` must print the same JSON as `python3 materials/nt_reference.py --json`

Every Notion feature named was read on the Notion Help Center on 9 October 2026; Notion changes
monthly, so re-check the help pages before teaching from it.

By Phoebe Fu.
